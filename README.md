# WellingtonList.com

The local guide to Wellington, Florida: news, restaurants, things to do, events and a local business directory.

## How it works
- **Static site** generated by `scripts/build.mjs` (Node, no dependencies) into `/docs`, served by GitHub Pages at wellingtonlist.com.
- **Content** lives in `src/`:
  - `src/data/places.json` directory listings (restaurants, attractions, parks, shopping)
  - `src/data/events.json` events calendar
  - `src/data/posts.json` + `src/content/blog/<slug>.html` blog posts (metadata, FAQs, sources + article body)
  - `src/assets/` styles, scripts, `config.js` (form endpoint and GA4 ID)
- **Submissions**: every form posts to a Google Apps Script web app (`tools/apps-script.gs`) that writes to a Google Sheet. Mark a row `Approved = yes` and the nightly GitHub Action publishes it.
- **GitHub Action** (`.github/workflows/build.yml`) rebuilds on every push and daily at about 5am ET.

## Add a blog post
1. Add metadata (title, description, FAQ, sources) to `src/data/posts.json`
2. Add the article body to `src/content/blog/<slug>.html`
3. Push. The sitemap, RSS feed, blog index and homepage update automatically.

## SEO built in
Pre-rendered HTML, unique titles and descriptions, canonical URLs, Open Graph and Twitter cards, JSON-LD (Organization, WebSite, BreadcrumbList, NewsArticle, FAQPage, ItemList, Event and LocalBusiness types), XML sitemap, robots.txt and RSS feed.
