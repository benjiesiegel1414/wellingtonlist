About Wellington Branch Library

Palm Beach County Library System branch serving Wellington, with books, programs for kids and adults, computers and study space.

The Wellington Branch is part of the Palm Beach County Library System and sits on Royal Fern Drive. It opened in 1997 and was expanded in 2007 from about 8,000 to 30,000 square feet, and it has ranked among the busiest branches in the system for checkouts. The library has a children's section, a teen area, study rooms, an 80-seat meeting room and a 10-seat conference room. Visitors can use free Wi-Fi, public computers, in-building laptops for cardholders, and printing, scanning and fax, and the branch runs computer training and regular programs for kids, teens and adults.
